# 高端极简透明水光护肤品广告摄影 - 浮空水珠与清透光影

- **生成目标**：高端护肤品精华液瓶身静物摄影，悬浮水滴与晶莹剔透的水波光影，极简纯净的商业广告大片。
- **分类**：`image` (图像生成 / 商业电商与产品)
- **推荐模型**：Flux.1-dev / Midjourney v6.1 / SDXL
- **推荐画幅**：`3:4` 或 `1:1`
- **商业用途**：电商主图、美妆品牌海报、杂志封面
