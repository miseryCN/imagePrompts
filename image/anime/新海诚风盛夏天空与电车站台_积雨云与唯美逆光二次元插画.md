# 新海诚风盛夏天空与电车站台 - 积雨云与唯美逆光二次元插画

## 1. 基本信息
- **生成目标**：新海诚画风日本乡村铁路小站，巨大的盛夏积雨云（入道云）与耀眼阳光，唯美清新的二次元壁纸级插画。
- **分类**：`image` (图像生成 / 动漫二次元)
- **推荐模型**：Niji 6 / Animagine XL / Stable Diffusion Anime
- **推荐画幅**：`16:9` 电脑桌面壁纸画幅
- **风格关键词**：Makoto Shinkai style, CoMix Wave Films aesthetic

## 2. 提示词正文 (Prompt)

```text
[艺术风格] 新海诚动画电影风格（Makoto Shinkai aesthetic, CoMix Wave Films quality），极其细腻的二次元唯美场景插画。
[核心主体] 日本乡村电车轨道站台，生锈斑驳的铁路信号灯，木质长椅上放着一个高中生皮质书包，微风拂动樱花与绿叶。
[天空与背景] 远方地平线上矗立着无比壮丽宏伟的盛夏积雨云（Cumulonimbus cloud / 入道云），云层层次极其丰富，受夕阳晕染出金橙、淡粉与青紫渐变。

[色彩与细节] 高饱和度晴空蔚蓝、翠绿与暖金光芒交织，画质清澈透明，超高分辨率，4K壁纸级艺术细节。
```
